## 二、参考视频玩法复刻清单（1:1）

原视频规格：672×1280 竖屏、42s 录屏、日式计算闯关。

必须复刻的核心要素：

1. **界面布局（自上而下 6 层）**
   - L1 顶部 HUD：关卡进度点阵、倒计时、总分
   - L2 数据条：`正解 N/10`、`失误 N`、`连击 N`（含倍率徽章 `×1.25`）
   - L3 关卡横幅：`EX 1` 大标题斜切彩带
   - L4 角色台：公仔站在粉色台面上待机
   - L5 题目白卡：题型标签 +「第 N 问」+ 竖排算式 + 右侧答题位
   - L6 数字键盘：`7 8 9 / 4 5 6 / 1 2 3 / ⌫ 0`

2. **出题与运算规则**
   - 题型带文字标签（小数减法、加法、乘法、除法、混合运算…）
   - 竖排算式 + 运算符在左、答案位在右
   - 支持小数、分数、括号

3. **答题输入方式**
   - 仅用底部数字键盘输入，支持退格 `⌫`
   - 输入内容实时显示在右侧红圈答题位
   - 键盘数字在连击升高时变为彩色高亮（视频中已观察到）

4. **计分与判定反馈**
   - 基础分 × 连击倍率
   - `正解 N/10` 进度、`失误 N` 累计
   - 答对：角色跳跃 + 星星迸射 + 彩带飘落
   - 答错：失误计数 +1，短暂红闪

5. **关卡/时间节奏**
   - 关卡制（EX 1…EX N），过关切横幅
   - 关卡内倒计时，答对**加时间**
   - 掉落物（金币/礼物盒）收集加分

## 三、改造增强需求（用户指定 5 项）

### 3.1 角色替换
用用户提供的 8 张素材替换原版公仔，保持动作与表情逻辑。

素材清单（已提取为透明底 PNG，位于 `assets/characters/`）：

|---|---|---|---|

| 兔耳小人-跳跃 | `bunny_jump.png` | 1024×1536 | 连击升级/跳跃 |
| 兔耳小人-闭眼 | `bunny_sleep.png` | 1024×1536 | 待机 |
| 白色小兔 | `rabbit.png` | 1230×1278 | 可选主角 |
| 白色小猫 | `cat.png` | 1024×1536 | 可选主角 |
| 蓝色小熊 | `bear.png` | 1236×1273 | 可选主角 |
| 黄色小鸡 | `chick.png` | 1254×1254 | 可选主角 |
| 角色方案图 | `styleguide.png` | 1536×1024 | 设计参考，不进游戏 |

**角色状态机**（保持原版逻辑）：
`idle 待机` → `answer 答题` → `correct 答对` → `combo 连击升级` → `wrong 答错` → `timeup 时间到`

主角可选（4 只），其余小动物在结算页作为「伙伴」出现。

### 3.2 难度曲线（递进 + 加速）
三层叠加，形成"停不下来"：

**A. 连击驱动难度（Difficulty Level, DL 1—10）**
- 每答对 1 题 +1 连击；连击每跨 5 → DL +1
- DL 提升 → 数值范围扩大、运算类型解锁、干扰项出现

**B. 时间压力加速**
- 每关基础倒计时（随年级可调，如 60s）
- 答对**奖励时间**：基础 +1.5s，DL 每级 +0.2s
- DL 越高，单题限时越短（软倒计时条压迫）

**C. 分数驱动**
- 分数越高 → 下一题 DL 基线越高（高分局不掉档）

**年级难度基线表**（认知水平对齐）：

| 年级 | 数值范围 | 运算类型 | 基准 DL | 单题限时 |
|---|---|---|---|---|
| 一年级 | 0—20 | 20以内加减 | 1 | 12s |
| 二年级 | 0—100 | 两位数加减、表内乘 | 2 | 11s |
| 三年级 | 0—1000 | 多位加减、乘除、有余除法 | 3.5 | 10s |
| 四年级 | 0—10000 | 三位数乘除、小数加减 | 5 | 9s |
| 五年级 | 0—100000 | 小数乘除、多位数乘除 | 6.5 | 8s |
| 六年级 | 0—1000000 | 分数、混合运算、括号 | 8 | 7s |

> 自适应：连续答错 2 题 → DL -1（保底不劝退）；连击 10+ → 解锁进阶题型。

### 3.3 视听刺激
- **BGM**：节奏感强循环（WebAudio 合成，无需音频素材，零体积）
- **音效**：按键 tick、答对上行音阶（随连击升调）、答错低鸣、升级闪白、连击心跳
- **视觉反馈**：连击特效（环形冲击波）、屏幕震动（按连击数增强）、高光扫过、粒子迸发、分数跳动（数字滚动+缩放弹跳）、金币飞行收集、关卡切屏彩带
- **可关闭**：静音按钮 + 震动开关（家长控制）

### 3.4 目标用户（1—6 年级）
- 界面全中文，提示语口语化（「算得真快！」「再快一点点！」）
- 配色明快：天蓝 + 亮黄 + 粉桃 + 薄荷绿，高对比大字号
- 大按钮（≥88rpx），防误触
- 按年级分组选择 + 难度手动微调（1—10 档）
- 无广告无内购干扰（家长友好）
- 支持键盘/触屏/鼠标三端输入

### 3.5 交付形态
- 完整可运行项目，含技术栈说明、结构划分、启动方式
- 各难度档位与角色素材的**替换位置明确标注**

## 四、技术栈决策

| 层 | 选型 | 理由 |
|---|---|---|
| 渲染 | **原生小游戏 Canvas 2D** | 竖屏逐帧动画 + 粒子 + 震动，Canvas 最直接；无需第三方引擎 |
| 语言 | **原生 JavaScript（ES2017+）** | 微信小游戏环境零构建、零依赖，双击开发者工具即可跑 |
| UI | **Canvas 自绘 + 少量原生组件** | 全屏沉浸，避免原生组件层级穿插 |
| 音频 | **WebAudio 合成** | 无音频文件依赖，包体极小 |
| 存档 | `wx.setStorageSync` | 离线、无需后端 |
| 云端 | 云开发（可选增强） | 排行榜/好友榜，可后置 |
| 跨端 | 共享核心 `shared/` + 适配层 | 同一套逻辑可跑微信小游戏 + H5 预览 |

**目录结构**

```
project/
├─ shared/            # 跨端共享核心（纯逻辑，无平台 API）
│  ├─ difficulty.js   # 年级难度表、DL 计算、题目生成器
│  ├─ scoring.js      # 计分、连击、倍率、判定
│  ├─ characters.js   # 角色状态机 + 素材映射（替换入口）
│  └─ config.js       # 全局配置（换皮/难度在此改）
├─ miniprogram/       # 微信小游戏工程（app.js/game.js/game.json）
│  ├─ game.js         # 主循环、输入、渲染编排
│  ├─ scenes/         # 主页/游戏/结算 三场景
│  ├─ ui/             # hud/question/keypad/banner 组件
│  ├─ fx/             # 粒子/震动/彩带/音效
│  └─ assets/characters/   # 角色 PNG（替换点）
├─ web/               # H5 版（浏览器直接跑，零依赖预览）
└─ docs/              # 说明文档
```
